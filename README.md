# Simulador de cantidad de AMR requeridos

Herramienta web React + TypeScript para estimar la cantidad de robots moviles AMR requeridos por una operacion industrial.

## Ejecutar

```bash
npm install
npm run dev
```

La aplicacion corre por default en:

```text
http://127.0.0.1:5174
```

## Validar build

```bash
npm run build
```

## Incluye

- Formulario guiado por demanda, ruta, tiempos, robot generico y entorno.
- Calculo en tiempo real de robots recomendados, capacidad, utilizacion y margen.
- Barra de utilizacion con estado operativo.
- Diagrama animado Origen -> Robot -> Destino.
- Resumen ejecutivo automatico.
- Logo y estetica CRBT Robots Moviles.
